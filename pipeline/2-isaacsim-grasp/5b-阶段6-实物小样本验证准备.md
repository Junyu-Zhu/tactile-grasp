# 5b — 阶段6：真实 UR5/Robotiq/GSmini 小样本验证准备（可与 5a 并行）

## 前置条件

`4-阶段4-确定性闭环早期纠偏.md` 已通过或至少已有稳定 event timeline。此阶段可以先准备协议，但不要在安全边界未定义时贸然执行真实硬件闭环。

## 目标

把 IsaacSim 中的 logging、risk score、控制事件和安全边界迁移到真实平台，为 JFR 的小规模实物验证做准备。

## 具体任务

1. 复用 IsaacSim event schema；
2. 定义真实平台安全边界：
   - gripper width 范围；
   - force/pressure 上限；
   - action frequency；
   - emergency stop/fallback；
3. 选择少量对象/材料：建议包含高摩擦、低摩擦、软/硬物体；
4. 设计 perturbation protocol：
   - lift acceleration；
   - object mass；
   - contact offset；
   - surface/friction；
5. 使用阶段3选出的 gated/calibrated score，不要直接使用 raw future risk；
6. 准备最小真实实验表格，不追求大规模。

## 产出文件

- `real_smoke_readiness_report.md`
- real logging schema
- safety checklist
- object/material list
- hardware fallback protocol

## 通过条件

- 不依赖 simulator-only oracle labels；
- 可以在真实平台记录同一套 timeline 字段；
- 有明确 fallback controller；
- 有安全上限；
- 明确哪些实验只是 smoke，不是统计显著结论。

## 完成后做什么

真实准备结果进入：

- `6-阶段7-JFR论文证据包.md`

如要实际跑真实硬件，应另开硬件执行计划和安全检查。
