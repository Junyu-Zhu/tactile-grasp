# 2b — 阶段2：仿真标签有效性 v2（可与 2a 并行）

## 与 2a 的关系

`2a` 负责模型能否跑通，`2b` 负责这些输出能否被严肃评估。没有本阶段，任何 slip 指标都只能是 proxy 或 smoke。

## 目标

把 IsaacSim 中的 force/slip 标签从“能跑通的 proxy”升级为“可用于指标的 sim-valid label”。

## 输入

- IsaacSim trial logs；
- object pose/velocity；
- gripper/contact frame；
- contact state；
- force/contact sensor output；
- timestep；
- release/drop/no-contact 标记。

## 具体任务

1. 定义 force frame 和单位：world / gripper / contact / sensor，单位是否为 N；
2. 定义 normal/tangential decomposition；
3. 定义 slip label：必须基于 gripper/contact frame 中对象相对切向运动；
4. 排除：
   - no-contact；
   - intentional release；
   - drop 后片段；
   - 只用 world XY proxy 的样本；
5. 为每帧生成：
   - `label_source`；
   - `valid_for_force_metrics`；
   - `valid_for_slip_metrics`；
6. 导出 Sparsh-compatible v2 dataset；
7. 写明哪些样本只能用于 smoke，哪些可以用于 metric。

## 产出文件

- `label_validity_report.json`
- `label_validity_report.md`
- `valid_masks.csv/json`
- v2 dataset manifest

## 通过条件

报告必须明确：

- `FORCE_LABEL_VALIDITY: invalid/proxy/sim-valid`
- `SLIP_LABEL_VALIDITY: invalid/proxy/sim-valid`
- `METRIC_VALIDITY: SMOKE_ONLY/PROXY_ONLY/METRIC_VALID`

只有 `sim-valid` 样本可进入阶段3的定量校准。

## 不能接受的捷径

以下不能单独作为 metric-valid slip label：

- world XY object motion；
- success/failure label；
- contact onset；
- release/drop；
- 几何占位 force；
- 没有 contact mask 的整体位移。
